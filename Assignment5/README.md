# Assignment 5: Arrays: Traversal and Counting

**Experiment Title:** Arrays: Traversal and Counting

**Aim:** Create an array, visit every element with a loop, and add up or count the values.

**Software / Tools Required:** Java Development Kit (JDK), Visual Studio Code (VS Code), and a terminal/command prompt.

**Theory:** An array stores multiple values of the same data type. Its index starts from 0, and arr.length gives the number of elements.

A loop can visit every array element. A sum variable adds the values, while a largest variable keeps the maximum value found so far.

A counter stores how many array elements satisfy a condition. It is increased whenever an element is greater than 10.
