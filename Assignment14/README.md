# Assignment 14: Characters: Counting and Positions

**Experiment Title:** Characters: Counting and Positions

**Aim:** Use charAt to count vowels and a letter, and print each letter with its position.

**Software / Tools Required:** Java Development Kit (JDK), Visual Studio Code (VS Code), and a terminal/command prompt.

**Theory:** A vowel is one of the letters a, e, i, o or u. The charAt() method can check each character of a String.

The charAt() method accesses each character at a specified index. A counter can count how many times a selected letter occurs.

String positions are called indexes and start from 0. charAt(index) returns the character stored at that position.
