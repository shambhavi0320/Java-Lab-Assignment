# Assignment 4: Writing Functions

**Experiment Title:** Writing Functions

**Aim:** Write functions with parameters and return values, and call them from main.

**Software / Tools Required:** Java Development Kit (JDK), Visual Studio Code (VS Code), and a terminal/command prompt.

**Theory:** A function is a reusable block of code. Factorial is used to calculate combinations: nCr = n! / (r! × (n-r)!).

Permutation gives the number of ways to arrange r objects selected from n objects. Its formula is nPr = n! / (n- r)!.

A function can accept parameters and return a value. The if-else statement can compare two integers.
