# Assignment 9: Matrices: Rows and Columns

**Experiment Title:** Matrices: Rows and Columns

**Aim:** Visit the rows and columns of a matrix with nested loops to print, add and count its values.

**Software / Tools Required:** Java Development Kit (JDK), Visual Studio Code (VS Code), and a terminal/command prompt.

**Theory:** Rows in a two-dimensional array are accessed by their row index. The first row has index 0 and the last row has index length - 1.

To calculate a column sum, the outer loop selects a column and the inner loop adds the values from all rows in that column.

A nested loop visits every element of a matrix. A counter increases whenever an element satisfies the condition.
