# Assignment 1: Hello World, Variables and Arithmetic

**Experiment Title:** Hello World, Variables and Arithmetic

**Aim:** Print text, store values in variables and calculate with arithmetic operators.

**Software / Tools Required:** Java Development Kit (JDK), Visual Studio Code (VS Code), and a terminal/command prompt.

**Theory:** System.out.println() displays text and moves the cursor to the next line.

Java variables store values of different data types. int stores whole numbers, double stores decimal numbers, char stores one character, and String stores text.

Arithmetic operators perform mathematical operations. The operators +, -, *, / and % are used for addition, subtraction, multiplication, division and remainder.

The final keyword makes a variable constant, so its value cannot be changed. The area of a circle is PI × radius × radius and its perimeter is 2 × PI × radius.
