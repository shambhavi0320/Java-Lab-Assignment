# Assignment 2: Decisions and Loops with Numbers

**Experiment Title:** Decisions and Loops with Numbers

**Aim:** Use if, else if and loops to make decisions and repeat steps with whole numbers.

**Software / Tools Required:** Java Development Kit (JDK), Visual Studio Code (VS Code), and a terminal/command prompt.

**Theory:** The modulus operator (%) gives the remainder. If a number divided by 2 has remainder 0, it is even; otherwise, it is odd.

An else-if ladder checks multiple conditions in sequence and executes the block whose condition is true.

A leap year is divisible by 400, or divisible by 4 but not divisible by 100.

The factorial of a positive integer is the product of all positive integers from 1 up to that number. A for loop repeats the multiplication.
