# Java Lab Assignments

Organized from the supplied **Java Lab Practical File Revised** PDF.

- **Assignments:** 15
- **Questions:** 49

## Folder structure

Each `AssignmentN` folder contains its own `README.md` and one folder per question. Each `QuestionN` folder contains `Main.java` and `Output.png`.

## Notes

- Java source code and expected output text were extracted from the supplied practical PDF.
- `Output.png` files are generated console-style images of the output printed in the PDF; they are not screenshots captured from a live Java execution.
- Run a question from its folder with a Java JDK installed, for example:

```bash
javac Main.java
java Main
```

The class is named `Main` in the practical file, so keep the filename as `Main.java`.
