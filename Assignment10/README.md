# Assignment 10: Switch and ArrayList

**Experiment Title:** Switch and ArrayList

**Aim:** Choose a branch with a switch statement, and store and change a list of numbers in an ArrayList.

**Software / Tools Required:** Java Development Kit (JDK), Visual Studio Code (VS Code), and a terminal/command prompt.

**Theory:** A switch statement selects one case based on the value of an expression. The default case handles values that do not match any case.

ArrayList is a resizable collection in Java. add() inserts elements, size() returns the number of elements, and get() accesses an element by index.

The set() method changes the value at a specified index. The remove() method deletes the element at the specified index.
